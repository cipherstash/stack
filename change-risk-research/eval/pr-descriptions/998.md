# fix(scripts): stop the lockstep bump failing on an unchanged version

## The lockstep bump now accepts an unchanged version

`bumpCargoPackageVersion` in `scripts/sync-lockstep-versions.mjs` returns the manifest unchanged when the `[package]` version already equals the target. Before this change, it threw an error.

## Every stack release after EQL 3.0.6 needs this fix

The function looked for the version line by checking whether the replace changed the text. When the version already matched, the text stayed the same, so the function threw `did not find a version line in the [package] section`. The function now checks for the version line directly.

A version run that leaves EQL's version alone reaches this case. After the EQL 3.0.6 release, every stack release leaves EQL's version alone, so every stack release would fail.

This is step 7 of Phase 0 in [the stack crates import plan](https://github.com/cipherstash/cipherstash-suite/blob/main/docs/plans/stack-crates-import.md). It must merge before the EQL 3.0.6 release in step 8.
